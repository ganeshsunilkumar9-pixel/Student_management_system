# Student Management System

A Django-based web application for managing student information.

## Features

- Add students
- View students
- Update student details
- Delete students
- Manage courses

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## How to Run

1. Clone the repository
2. Create a virtual environment
3. Install Django
4. Run migrations
5. Start the Django server

```bash
python manage.py migrate
python manage.py runserver
